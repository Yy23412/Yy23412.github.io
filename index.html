PROJECTS

两个装备项目，都是先有现场问题，再谈方案。

2024.09 — 2025.07

输电线路垂直轴风储供电系统特种风机团队 · 核心成员

垂直轴风机 / 变桨与变速 / 储能与防雷 / 结构设计

输电线路沿线取电条件差、多元场景存在供电缺口，小型风机在小风速下启动慢、极端风况下结构可靠性不足。 参与变速、变桨、柔性扇叶、快装固定四类结构的方案设计与建模，配合动态转速调控与实时桨距优化， 让扇叶随风速自适应调节；参与抗风保护与储能、防雷模块的结构校核。 获全国大学生高电压与等离子体科技创新竞赛省级二等奖、“挑战杯”省级三等奖。

项目详情

技术路线　风机被拆成四类关键结构分别攻关：变速装置、变桨装置、柔性扇叶、快装固定装置；控制侧配套动态转速调控与实时桨距优化，让扇叶随风速自己调整迎风角。

我做的事　四类结构的方案设计与三维建模；配合桨距优化做结构接口与行程校核；抗风保护、储能与防雷模块的结构配合校核。

难点　小风速要好启动、极端风况要扛得住，这两件事在结构上是打架的；团队用柔性扇叶卸载荷、用实时变桨调迎风角，把矛盾拆开处理。

结果　省级二等奖 + 省级三等奖；相关结构形成实用新型专利（受理号 2025202226754）。

2024.03 — 2024.12

智能化高精度桩孔及管道检测管测“先行者”团队 · 核心成员

360° 全景检测 / 地磁定位 / 三维成像 / YOLOv5

管道内壁检测设备与工序差异大、流程冗长，缺陷判读依赖人工经验，综合成本高。 沿“切片式 360° 全景采集 → 旋转地磁定位 → 三维合成成像 → YOLOv5 缺陷识别”搭建检测链路， 承担采集端结构论证与成像测试。 获中国大学生机械工程创新创意大赛国家级二等奖、云说新科技科普传播大赛国家级三等奖、 中国国际大学生创新大赛省级三等奖。

项目详情

技术路线　把检测链表成四段：切片式 360° 全景采集 → 旋转状态下的地磁传感定位 → 三维高精度合成成像 → YOLOv5 缺陷识别。

我做的事　采集端的结构方案论证；成像链路的测试与数据核对，负责把“拍到的”和“拼出来的”对上。

难点　探头在管道里是转着走的，图像拼接必须先知道自己在哪；地磁定位解决姿态，三维合成解决拼接，最后才轮到 YOLOv5 认缺陷——顺序错了后面全白做。

结果　国家级二等奖、国家级三等奖、省级三等奖各一项。
